# 矿权日报 Agent 产品设计

## 背景与目标

用 MCP 把新闻、储量 PDF、价格拆成三个可独立调用的服务，再用一个 Agent 串成「矿权日报」。

审查人员要在约 5 分钟内跑通主流程，并确认三个服务能接到 Cursor 或 Claude Desktop。本次不展开真实数据源和业务规则，优先保证功能链路可用、结果可重复。

默认输入：

> 给我生成一份关于 Pilbara 锂矿的今日简报

默认输出：一份 Markdown 简报，包含新闻摘要、储量数据、价格走势、风险提示，并附来源链接。

## 使用对象

- **审查人员**：用 Docker 看完整简报，用桌面端确认 MCP 工具可调用。
- **接入方**：把三个 MCP 服务配进 Cursor 或 Claude Desktop，单独调用工具。

日报由本仓库的 Agent 生成。桌面端里的模型只用于验证工具是否接通，不负责编排简报。

## 产品范围

本次交付：

- 3 个 Python MCP 服务
- 1 个 LangGraph Agent，负责编排并输出简报
- `mcp-config.json`，可接到 Claude Desktop / Cursor
- `RUN.md` 与一条 `docker-compose`，用于快速跑通

不在本次范围：

- 实时抓取、付费行情、多矿区覆盖
- 模型 API（无 key 也必须能出简报）
- 储量口径、价格品种、风险阈值等业务细则

## 整体方向

数据全链路默认走 fixture，环境变量为 `MINING_DATA=fixture`。未设置时同样走 fixture。Docker、Cursor、Claude Desktop 使用同一开关，审查时看到的数据一致。

三个服务通过 stdio 提供工具。Agent 按配置拉起这三个子进程，调用完成后关闭。桌面端使用同一套服务，配置由本机脚本生成，写入绝对路径、工作目录和上述环境变量，避免审查机器因找不到 `python` 或工作目录不对而接失败。

## 主要功能

### 新闻服务 `mining-news-mcp`

- `search(query, days)`：按关键词和时间窗口返回新闻列表（标题、链接、日期、摘要）
- `fetch_article(url)`：按链接返回正文，并带上来源

### 储量服务 `mineral-pdf-mcp`

- `extract_resources(pdf_url)`：从 PDF 抽出 Indicated / Inferred 储量，并带上来源

演示所用 PDF 放在仓库内，调用不依赖外网。

### 价格服务 `lme-price-mcp`

- `get_price(commodity, date)`：返回指定日期的价格
- `get_trend(commodity, days)`：返回一段时间内的价格走势

### 日报 Agent

主流程四步：

1. **解析**：从输入句得到地区、矿种、日期和新闻窗口
2. **并行取数**：同时调用 `search`、`get_price`、`get_trend`
3. **补全**：对新闻链接调用 `fetch_article`，对 fixture 中的 PDF 调用 `extract_resources`
4. **成文**：用模板拼成 Markdown，不调用大模型

默认查询写在程序里。Docker 启动时不把中文查询放在命令行参数中。需要更换句子时，用环境变量 `BRIEF_QUERY` 覆盖。

### 接入与审查

- `scripts/setup.ps1`：创建虚拟环境、安装依赖，并生成 `mcp-config.json` 与 `.cursor/mcp.json`
- Docker：`docker compose up --build` 在终端输出完整简报
- Cursor：打开仓库并重载后，可看到三个服务已连接
- Claude Desktop：将生成的 `mcpServers` 合并进本机配置后重启即可调用

## 验收

1. 执行 `docker compose up --build` 后，终端输出含新闻摘要、储量、价格走势、风险提示和来源链接的 Markdown。
2. 执行 setup 并重载 Cursor 后，三个 MCP 服务为已连接；`search`、`extract_resources`、`get_price` 能返回 JSON。
3. 上述路径均在 `MINING_DATA=fixture` 下完成，不需要模型 API key，也不需要访问外网。
